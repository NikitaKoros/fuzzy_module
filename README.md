# Нечёткие величины на основе равномерного распределения

Go-модуль `fuzzylab` (корень `realisation/`) состоит из слоёв, зависимости идут только вниз:

- `fuzzy/` — расчётное ядро: `core`, `number`, `ops`, `compare`, `metrics`, `set`;
- `gen/`, `cluster/` — генерация наборов и кластеризация поверх ядра;
- `storage/`, `logger/` — хранение наборов в CSV и журнал действий в JSON;
- `web/`, `cmd/app/` — веб-интерфейс (html/template + htmx) и исполняемая программа.

Исходная плотность равномерного распределения на `[a, b]` сохраняется методом `Uniform.Density`. Функция распределения доступна через `Uniform.CDF`. Функция принадлежности строится как CDF, ограниченная исходным носителем: `μ(x)=CDF(x)` при `a <= x <= b` и `0` вне него. Поэтому `Uniform` представляет правостороннюю треугольную нечёткую величину `(a, b, b)`, а её α-срез при `0 < α <= 1` равен `[a + α(b-a), b]`. Это не обычная CDF на всей числовой оси: после `b` функция принадлежности обнуляется. По контракту `core.Number` вызов `AlphaCut(0)` возвращает замыкание носителя `[a, b]`; для `0 < α <= 1` возвращается `[a + α(b-a), b]`.

## Запуск программы

Нужен Go 1.24 или новее. Интернет и внешние зависимости не нужны.

```bash
make run
```

Это то же, что `go run ./cmd/app`.

Затем открыть `http://localhost:8080`. Флаги: `-addr` (адрес сервера, по умолчанию `localhost:8080`) и `-data` (каталог для наборов и журнала, по умолчанию `data`).

Слева задаются уровень α (ползунок и поле ввода), алгоритм кластеризации, параметры генерации и имя файла. Справа показаны срезы величин, плоскость границ срезов и таблица кластеров. Наборы сохраняются в `data/<имя>.csv`, а загружаются из `data/input/<имя>.csv` (положите туда файл формата `kind,a,b`, строки вида `uniform,1,3`). Журнал действий пишется в `data/log.json`.

## Пример использования

```go
a, _ := number.NewUniform(1, 3)
b, _ := number.NewUniform(2, 5)
sum, _ := ops.Add(a, b, core.Config{}) // α-срез: [3 + 5α; 8]
```
